# Polices des documents PDF

Les polices de ce dossier sont incorporées aux factures et aux soumissions afin que leur rendu ne dépende pas du système d'exploitation du serveur.

- `liberation-sans/` : Liberation Sans 2.1.5, provenant de la [publication officielle](https://github.com/liberationfonts/liberation-fonts/releases/tag/2.1.5), sous SIL Open Font License 1.1.
- `roboto-condensed/` : Roboto Condensed Bold, provenant du [projet officiel Roboto 2](https://github.com/googlefonts/roboto-2), sous Apache License 2.0.

Les licences complètes sont conservées dans le dossier de chaque famille.
